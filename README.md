# Article Site

A modern article management website built with **React**. This project demonstrates component-based architecture, routing, API integration, reusable UI components, and state management.

## ✨ Features

* 📰 Display articles
* ➕ Create new articles
* 📖 View article details
* 🔍 Dynamic content loading
* ⚡ Fast and responsive UI
* 🎨 Modular component structure
* 🌐 React Router navigation
* 🔄 API communication with Axios
* 📦 JSON Server for local backend

## 🛠️ Technologies

* React
* React Router
* Axios
* JavaScript (ES6+)
* HTML5
* CSS3
* Vite
* JSON Server


## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/RadmehrJafarinezhad/article-site.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Run the JSON Server:

```bash
npx json-server src/data/db.json --port 3000
```
